# 短剧带货脚本引擎 · Drama Selling Script

把"产品卖点讲解"升级为"短剧剧情带货"：**用一段好看的短剧把产品卖点自然植入**，一键生成可直
接投喂 Seedance 的分镜脚本。解决旧版"基于卖点罗列、不够吸引人"的问题——观众是因为想看结局、
代入角色而看，卖点通过角色真实困境自然流露，而非生硬口播。

## 与旧版（ai-video-script-engine）的本质区别

| 维度 | 旧版 | 本版 |
|---|---|---|
| 叙事 | 卖点维度组合 + 痛点地图 | **短剧结构驱动**（反转/霸总/闺蜜/悬疑…）|
| 开场 | 痛点口播 | **前 3 秒剧情悬念/冲突/反差** |
| 产品角色 | 被介绍的客体 | **剧情的必需品/关键道具/转折筹码** |
| 吸引力 | 信息密度高但像广告 | 像短剧，先好看再种草 |
| 下游 | 导出分镜 | 额外输出 **Seedance 分镜提示词** |

## 功能

- 商品信息录入（卖点 / 场景 / 人群 / 价格）
- **10 种短剧风格**：反转逆袭、霸总甜宠、闺蜜种草、家庭温情、悬疑探案、搞笑沙雕、情感治愈、
  职场逆袭、测评打假、夫妻婆媳——每种带独立叙事节拍与植入策略
- 时长（15/30/60/90s）、平台（抖音/视频号/小红书/快手/TikTok）、语气参数化
- 痛点地图 → 短剧分镜两段式生成
- 卖点植入地图、人物跨镜头一致性锚点
- 平台合规扫描 + 一键合规改写（违禁/限用词）
- 导出 Markdown / JSON，复制全文

## 部署（拿到新链接）

### 方式 A：静态站直接部署（推荐，立即拿链接）
纯前端，**默认走 SiliconFlow（OpenAI 兼容 + 浏览器 CORS 友好，可调用 DeepSeek 模型）**。
`npm install && npm run build` 后，把 `dist/` 部署到任意静态托管（CloudStudio / Vercel / Netlify /
对象存储）即得到新链接。前端「设置」填 SiliconFlow 的 Key 即可使用。

### 方式 B：Render 部署原生 DeepSeek（无 CORS 问题）
仓库内置 `server/proxy.cjs` 与 `render.yaml`。在 Render 控制台 New → Blueprint → 连接本仓库，
自动建 Web Service；部署后前端选「自托管代理」模式填 DeepSeek Key 即可。

## 5条批量生成（最小可用版）

1. 设置 API Key 与模型后，切换到「5条批量 · 15秒」。
2. 一次填写五个商品的名称与卖点；也可把单商品信息复制到五条，分别修改卖点，生成同一商品的五个角度。场景、人群、补充信息沿用原商品结构。
3. 选择共同的风格、平台和语气。批量时长固定为15秒；单商品仍可选择原有时长。
4. 点击「生成全部5条」。每条顺序调用原来的「痛点地图 → 短剧分镜」流程（完整批次共10次模型请求），同时避开本批次此前的开场。某条失败继续下一条，可单独重试；取消停止后续请求并保留已完成结果。
5. 展开结果，查看原有分镜、卖点地图、Seedance提示词和风险词扫描。编辑发布字段后，点击批量 Markdown 或 JSON 导出。两种导出均保留全部五条、生成状态和错误信息，Markdown复用原单条导出函数。

批量输入和结果保存在当前浏览器 localStorage（`dse_batch_v1`），刷新可恢复；刷新时正在生成的行标为已取消，需手动重试。生成过程中暂时锁定输入；重新生成一条会替换该条旧脚本，保留已有发布文案。JSON包含`version`、`duration`、`timezone`和`items`，每行保留`product`、`publication`、`script`、`painMap`、`meta`、`compliance`、`status`、`error`，不包含API设置。

### 发布前仍需手动确认

- **挂车状态**：默认待确认，可选挂车/不挂车。确认账号权限、商品链接及视频对应商品；本工具不自动挂车。
- **标题**：模型草稿，建议20字以内，核对剧情和商品事实。
- **话题**：模型草稿，最多5个，核对平台及内容相关性。
- **购物车标题**：模型草稿，建议10字以内，核对真实商品；不挂车时可留空。
- **发布时间**：手动填写日期与时间，统一解释为北京时间（Asia/Shanghai），不自动预约发布。
- **商品卖点、人物与脚本**：核对实物形态、规格、测试/功效依据、人物一致性、风险词及15秒实际可读时长。批量模式沿用原单商品人物提示，不保证五条生成同一人物；如需固定人物，请在每条补充信息重复写入设定。

只为留空的标题、话题、购物车标题填入生成草稿，不覆盖已填写的字段。批量结果中的合规页仅扫描提示，修改需人工处理；原单商品的一键合规改写保留。未接入视频生成、封面生成或抖音发布接口。

验证：`node --test`运行批量队列、取消、失败、重试、发布字段保留及导出测试；`npm run build`验证生产构建。测试使用模拟模型响应，真实生成需自行配置API。
